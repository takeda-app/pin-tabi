# ピン旅

出発駅と到着駅（必要なら経由駅）を選ぶと、全国の鉄道からルート候補を探します。選んだルートは、日本地図の上で実際の線路の形に沿ってピンが走って進みます。

## できること

- 全国の鉄道 約580路線・約9,000駅（JR・私鉄・地下鉄・モノレール・路面電車）
- 出発・到着・経由駅（最大3つ）の指定。入力欄の候補からも、地図上の駅のタップでも選べます
- ルート候補を最大5件表示（早い順／乗換が少ない順）。発時刻からの到着時刻も出ます
- 再生するとピンが線路の上を走り、駅の混み具合に合わせて地図が自動でズームします
- 走行中の区間を、左の乗換プランで色付き表示
- ピンの速さを調整可能（1秒で30秒ぶん〜2時間ぶん）
- スマートフォン表示とダークモードに対応

## 動かし方

`index.html` は、同じフォルダの `rail.json` を読み込みます。ブラウザのセキュリティ制限により、`index.html` をダブルクリックで直接開くと（`file://`）データを読み込めません。次のどちらかの方法で開いてください。

**ローカルで確認する場合**

```bash
cd pintabi
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

**GitHub Pages で公開する場合**

リポジトリの Settings → Pages で、公開元にこのフォルダのあるブランチを指定してください。ビルドは不要です。

## ファイル構成

```
index.html              アプリ本体（HTML・CSS・JavaScript を1ファイルにまとめたもの）
rail.json               路線・駅・線路形状のデータ（約1.5MB）
tools/build_graph.py    国土数値情報の鉄道データから駅の並びと駅間の線路形状を作る
tools/pack_data.py      上の結果を rail.json にまとめる（乗換駅のグループ化、路線色、速度）
```

## 路線データの作り直し

新しい年度の鉄道データが出たときは、次の手順で `rail.json` を作り直せます。必要なのは Python 3 だけで、追加のライブラリはいりません。

1. 国土数値情報ダウンロードサイトの「鉄道」のページから、全国のデータ（例: `N02-25_GML.zip`）をダウンロードして展開します。
2. 次を実行します。

```bash
python3 tools/build_graph.py N02-25_GML/UTF-8 graph_raw.json
python3 tools/pack_data.py 10 graph_raw.json rail.json
```

`pack_data.py` の最初の引数は線路形状の間引き幅（約1m単位）です。大きくするとファイルが軽くなり、線路の形は粗くなります。

ダウンロードした元データ（`N02-*_GML/`）と途中ファイル（`graph_raw.json`）はサイズが大きいので、`.gitignore` でリポジトリから外しています。

## 計算の仕組みと制約

- **所要時間**：線路の長さを、路線の種類ごとの平均速度で割って出した目安です。速度は新幹線 時速215km、JR在来線 62km、私鉄・地下鉄 45km、モノレール等 32km、路面電車 22kmで、1駅ごとに0.5分を足しています。実際の時刻表とは異なります。
- **乗換時間**：同じ事業者のJR線どうしは3分、同じ事業者のそれ以外は5分、別の事業者へは8分としています。東海道・山陽新幹線のように直通運転がある組み合わせは0分です。
- **乗換駅**：データの「駅グループ」が同じ駅と、同じ名前で600m以内にある駅を、1つの乗換駅として扱います。
- **路線名**：データの法律上の路線名をそのまま使っています。そのため、山手線の東京〜品川が「東海道線」になるなど、普段の呼び方と違う区間があります。
- **海岸線**：縮小表示用の簡略な形を手作業で入れたもので、拡大すると薄くなって消えます。

## データの出典

「国土数値情報（鉄道データ 2025年度版）」（国土交通省）を加工して作成しています。
リポジトリで公開する場合は、国土数値情報の利用規約を確認し、この出典表記を残してください。

アプリ内の文字には Google Fonts（Dela Gothic One、Zen Kaku Gothic New、Chivo Mono）を読み込んで使っています。
